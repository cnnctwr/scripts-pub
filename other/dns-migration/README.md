# DNS-Migration Strato → Hetzner

Im Zuge der Server-Migration zu Hetzner soll auch die DNS-Zone der Hauptdomain mit ihren rund 30 Subdomains von Strato zu Hetzner umziehen. Die Anleitung beschreibt einen risikoarmen Weg: Zuerst ziehen nur die Nameserver um, die Domain bleibt vorerst bei Strato registriert, und der Wechsel lässt sich jederzeit zurückdrehen.
